# DEX Native TV Starter — 0.1

A minimal native Android TV prototype for Xiaomi Mi TV P1 / Android TV 10.

## What is included
- Landscape TV-first activity and remote-focusable button
- Dark holographic orb command-centre UI
- Android speech-recognition intent (availability depends on TV speech services)
- Text-to-speech response
- Small local demo responses
- GitHub Actions workflow that builds a debug APK in the cloud

## What is NOT implemented yet
- No real AI model/backend or persistent memory
- No wake-word listener
- No Notion, Outlook, or WhatsApp integrations
- No Google Assistant replacement or remote Assistant-button remapping
- No guaranteed support for every Xiaomi firmware variant

## Cloud build
1. Create a GitHub repository and upload these project files.
2. Commit to the `main` branch, or open Actions and run **Build DEX Android TV APK**.
3. Open the completed workflow run and download the `DEX-TV-debug-APK` artifact.
4. Install the APK on your own TV only after reviewing the permissions and behavior.

## Build settings
- `minSdk 29` (Android 10)
- Java 17 / Kotlin
- Android Gradle Plugin 8.6.1
- Compile SDK 35

The build uses a debug signing key generated by the CI build. It is for testing, not a production release.

## Remote-button research
ADB-based remote key mapping is a separate milestone. The Assistant button may be intercepted by firmware or may trigger both the original Assistant and DEX. Test the exact TV model and firmware before changing system behavior. Do not disable Google packages as an initial experiment.

## Security
Do not put AI provider API keys in the Android app. The next phase should call a secure backend that stores credentials server-side.
